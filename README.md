# React Portfolio Project

A simple Vite + React portfolio website with sections for About, Projects, and Contact.

## Setup

1. Install dependencies
   ```bash
   npm install
   ```
2. Start the development server
   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
```

## Git

Initialize a repository and add a remote if you want to push this project:

```bash
git init
git add .
git commit -m "Initial portfolio project"
# replace <remote-url> with your repo URL
git remote add origin <remote-url>
git push -u origin main
```
